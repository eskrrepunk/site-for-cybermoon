# 🌙 CYBER MOON — Сайт киберспортивного клуба (г. Кириши)

Современный адаптивный одностраничный сайт (лендинг) для компьютерного клуба **CYBER MOON**. Проект выполнен в темной неоновой киберпанк/аниме-стилистике с эффектами матового стекла (glassmorphism), интерактивным прайс-листом и формой быстрого бронирования игровых мест.

🔗 **Демо-версия сайта:** [cyber-moon-kirishi.netlify.app](https://netlify.app)

---

## ✨ Основные разделы и функционал

* **Навигация и Hero-блок:** фиксированная шапка с векторным SVG-логотипом, адаптивным мобильным меню и атмосферным первым экраном.
* **О клубе и железо:** карточки с конфигурациями игровых зон (**Standard Zone** и **VIP Bootcamp**).
* **Интерактивные тарифы:** переключение пакетов времени (Будни / Выходные / Пакеты) с наглядными карточками цен.
* **Турниры (CYBER MOON LOBBY):** анонс локальных киберспортивных турниров (Dota 2, CS2) и кнопка регистрации команд.
* **Галерея клуба:** адаптивная сетка фотографий игровых залов и атмосферы клуба.
* **Контакты и онлайн-бронь:** адрес, график работы, прямая ссылка на сообщество ВКонтакте, форма быстрой брони на странице и всплывающее модальное окно.

---

## 🛠️ Технологический стек

Проект написан без тяжелых сборщиков и фреймворков для максимальной скорости загрузки и простоты деплоя:

* **HTML5** — семантическая разметка страницы.
* **Tailwind CSS (CDN)** — адаптивная сетка, отступы и утилитарные классы.
* **CSS3 (`style.css`)** — кастомные неоновые свечения, градиенты, glassmorphism и анимации.
* **Vanilla JavaScript (`script.js`)** — логика модальных окон, переключение вкладок тарифов, мобильное меню и валидация форм.
* **Google Fonts** — шрифты `Unbounded` (для заголовков) и `Manrope` (для основного текста).
